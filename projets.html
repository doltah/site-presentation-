Projets GitHub

Avec GitHub, j’ai commencé par développer plusieurs projets en C et C++, parmi lesquels : Hello World (comme tout le monde), Snake, et Devine un nombre.

Pour enrichir ces projets, j’ai utilisé différentes librairies afin d’améliorer le rendu graphique et l’interactivité.

Je ne me suis pas arrêté là : j’ai ensuite combiné développement logiciel et infrastructure, en intégrant du HTML et du YAML. J’ai ainsi auto-hébergé le site web sur lequel vous vous trouvez actuellement, visible dans la sous-rubrique Projets GitHub.

Un workflow GitHub me permet de déployer automatiquement chaque modification effectuée sur le dépôt.

Quelques informations techniques

  • Serveur : Ubuntu 24.04.3 LTS
  • Hébergement : serveur personnel (auto-hébergé)
  • Serveur web : Nginx 1.24.0 (Ubuntu)
  • CI/CD : Workflow GitHub en YAML
  • Déploiement : automatisé via YAML & SSH
